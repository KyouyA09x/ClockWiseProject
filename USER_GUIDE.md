# Quick Start Guide - New Features

## 🎨 Accessing Settings

1. **Open the Navigation Drawer:**
   - Tap the **hamburger menu icon** (☰) in the top-left corner
   - The drawer will slide in from left to right

2. **Navigate to Settings:**
   - In the drawer menu, tap **"Settings"**

## 🌗 Changing Theme Mode

In Settings, you'll see three square buttons:

- **☀️ Light**: Always use light theme
- **🌙 Dark**: Always use dark theme
- **🔄 Auto**: Follow system theme (recommended)

Tap any button to switch modes instantly.

## 🎨 Changing App Theme Color

Below the theme mode buttons, select from:
- **Default Blue** - Original ClockWise blue
- **Cyan** - Modern cyan/turquoise
- **Green** - Nature-inspired green
- **Purple** - Rich purple tones
- **Orange** - Warm orange hues

Each theme works in both light and dark modes!

## 🔔 Alarm Improvements

The app now has enhanced stability:
- Alarms won't cause app crashes or restarts
- Better handling when device reboots
- Improved notification reliability
- Safe background operations

## 📱 Navigation Drawer Menu

Accessible from the hamburger menu:
- **History**: View completed tasks
- **Settings**: Customize themes and preferences
- **About**: App information (coming soon)

## Tips

- **Theme persists**: Your theme choice is saved and remembered
- **Auto mode**: Automatically switches between light/dark based on your device settings
- **Smooth transitions**: Themes apply instantly when changed
- **Battery friendly**: Dark mode saves battery on OLED screens

## Troubleshooting

**Theme not applying?**
- Force close and reopen the app
- Clear app cache if needed

**Drawer won't open?**
- Make sure you're tapping the hamburger icon (☰) in top-left
- Try swiping from the left edge of the screen

**Alarms not working?**
- Check notification permissions in device settings
- Ensure "Do Not Disturb" isn't blocking notifications
- Verify battery optimization is disabled for ClockWise
